# Muzicz — Design Brief Pack (for Claude Design)

This folder is a **self-contained** documentation pack describing the Muzicz Flutter music
player app exactly as it is implemented in code today (version `2.0.0+18`, August 2026).
It was generated by exhaustively reading the source, so a designer can work from these
files alone — no access to the codebase or a running device is required.

**Purpose:** feed this pack to a design-focused AI (or a human designer) to
(a) redesign the app, or (b) propose improvements to UI, animation, and transitions.

## Ground rules for any redesign proposal (summary — details in file 07)

1. **Liquid glass scope is frozen at its current usage** (bottom nav bar + mini player,
   opt-in via a setting). You may *propose* expanding or changing it, but every such
   proposal must be clearly marked as a proposal, must include a performance impact
   assessment, and must not be presented as a decided change. The app has shipped
   premium-quality glass with **no device profiling done yet** — this is a documented,
   acknowledged risk.
2. **Performance is a first-class constraint.** The codebase deliberately avoids
   shimmer, Lottie, Rive, hero animations, and per-frame provider notifications.
   Proposals should respect the established patterns (RepaintBoundary isolation,
   subtree gating, low-frequency update streams) or explain the cost of breaking them.
3. **The app is Vietnamese-first.** All user-facing copy is Vietnamese; keep proposals
   compatible with the existing copy (or propose copy changes explicitly).
4. Portrait-only, edge-to-edge, Material 3, single font family (Outfit), dark theme
   is the default of three themes (Dark / AMOLED / Light).

## App identity at a glance

- **Name:** Muzicz Audio (package `muziczz`)
- **Platform:** Flutter (Android is the primary target; Impeller enabled)
- **What it does:** local-music player (scans device MediaStore), with playlists,
  favorites, synced lyrics, sleep timer, playback speed, an audio-reactive visual mode,
  and a separate URL-downloader feature (downloader is **out of scope** for this pack)
- **Brand:** purple `#9D50FF` on near-black `#080808`, paired with rose `#C25169`,
  Outfit typeface, rounded-everything (radius 10–26), soft colored glows instead of
  Material elevation
